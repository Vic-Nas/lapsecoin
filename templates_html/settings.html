Settle window
While this node is still computing its own VDF for the next block, it starts a short timer the moment it sees a valid competing candidate for that same height (or the moment its own VDF finishes, whichever comes first). When the timer runs out, it stops waiting and picks a winner from whatever candidates it has, aborting its own attempt if it hasn't finished yet rather than running it to completion against a height that's likely already settled elsewhere. This is a local, per-node choice, not a network rule -- other nodes are unaffected by your value.
